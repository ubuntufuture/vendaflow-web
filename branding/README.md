# Fontes de identidade Venda Flow AI

`brandboard.png` é cópia byte a byte de `referencias/stitch_venda_flow_design_system/brandboard_venda_flow_ai.png/screen.png`, fornecido pelo usuário. Não é logo e não deve ser recortado nem usado como assinatura produtiva. A única cópia servida está no sandbox de revisão, na página de comparação.

`tokens.json` foi criado com as cinco cores EXATAS autorizadas no Super Prompt 02, que resolve a ausência de tokens registrada na etapa 01. Os modos semânticos, espaçamentos e demais decisões estão descritos em `docs/ui/DESIGN-SYSTEM.md`. Nenhuma decisão modifica o contrato de API ou a arquitetura do produto.

O SVG oficial validado por direção de arte continua ausente. `Wordmark` é um placeholder em Inter com o nome correto, sem símbolo redesenhado. Aprovação final da assinatura e do modo escuro permanece pendente; o brandboard não demonstra um sistema dark completo.
